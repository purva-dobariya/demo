# D2C approved prototype snapshot

This folder is the self-contained archive of the approved ONDC D2C prototype, including the Network Filmstrip version of “One integration. Many storefronts. Better economics.”

Open `index.html` through the repository's local web server. The snapshot owns its stylesheet, scripts, logo, D2C raster assets, approved reference comp, implementation inventory, and desktop/mobile review captures.

The production integration has intentionally not been implemented from this folder. See `actual-site-integration-plan.md` for the next-step plan.

## Snapshot map

- `index.html` — standalone prototype page
- `styles.css` — prototype styling
- `script.js` and `signup.js` — prototype interactions
- `assets/` — local image and logo dependencies
- `reference/` — approved Network Filmstrip comp and prompt provenance
- `screenshots/` — verified desktop and mobile captures
- `screenshots/production-integrated-*.png` — final production-section verification captures
- `design-notes.md` — broader D2C design direction
- `implementation-inventory.md` — section implementation inventory
- `actual-site-integration-plan.md` — scoped plan for adapting the filmstrip to the production D2C page
